# CopyThat 3.2.1

## 中文

- `EditInPreview.copythatplugin` 现在统一支持直接复制的图片和 Finder 图片文件。
- 删除重复的 `EditImageFileInPreview.copythatplugin` 示例。
- 合并主程序的图片临时文件生成路径，并补充运行时格式和大小校验。
- 修复微信、Word 等软件仅选中文字时可能重复显示上一次文字或图片通知的问题。

## English

- `EditInPreview.copythatplugin` now handles both copied image data and Finder image files.
- Removed the duplicate `EditImageFileInPreview.copythatplugin` example.
- Unified temporary-image materialization and added runtime format and size validation.
- Fixed repeated text or image notifications caused by selection-only pasteboard churn in apps such as WeChat and Word.
