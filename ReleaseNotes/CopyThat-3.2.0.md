# CopyThat 3.2.0

## 中文

- 新增 Host API v2 与图片文件匹配类型。
- 导入 `EditImageFileInPreview.copythatplugin` 后，从 Finder 复制图片文件会同时显示“在预览中编辑”和“在访达中显示”。
- 浮窗最多显示两个适用操作；旧版 schema v1/v2 插件继续兼容。

## English

- Adds Host API v2 and the image-file match type.
- With `EditImageFileInPreview.copythatplugin` installed, copied Finder image files show both “Edit in Preview” and “Show in Finder”.
- The HUD supports up to two applicable actions while existing schema-v1/v2 plugins remain compatible.
